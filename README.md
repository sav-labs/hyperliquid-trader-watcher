# Hyperliquid Trader Watcher (Telegram Bot)

Telegram-бот на **Python 3.13.2**, который отслеживает действия трейдеров на DEX **Hyperliquid** и присылает алерты:

- изменения позиций (открытие/изменение/закрытие)
- ликвидации (best-effort по `userNonFundingLedgerUpdates`)
- пополнения баланса
- выводы средств

Ключевые особенности UI:

- **доступ по заявкам**: новые пользователи попадают в `pending`, админы одобряют
- **персональные списки трейдеров**: у каждого пользователя свои адреса и свои алерты
- **управление трейдерами**: добавление списком/по одному, удаление через **inline**-кнопки
- **админ‑панель**: одобрение/блокировка пользователей, настройка доставки в канал
- **контроль типов алертов**: админ может включать/выключать пользователю алерты по позициям/ликвидациям/депозитам/выводам
- по умолчанию алерты идут в **ЛС**, отправку в **канал** настраивает только администратор

> Для доступа к API Hyperliquid используется `hyperliquid-python-sdk`.

## Быстрый старт (локально)

1) Активируйте виртуальное окружение (у вас уже есть `env/`):

```bash
cd /Users/artemsolovev/github-sav116/hyperliquid-trader-watcher
source env/bin/activate
```

2) Установите зависимости:

```bash
pip install -r requirements.txt
```

3) Создайте `.env`:

- Скопируйте `.env.example` → `.env`
- Заполните `BOT_TOKEN` и `BOT_ADMINS`

4) Запуск:

```bash
python main.py
```

Данные (SQLite БД и логи) по умолчанию пишутся в `./data/`.

## Деплой через Docker

Требования: установлен Docker.

1) Создайте `.env` как описано выше.
2) Запустите:

```bash
chmod +x ./deploy.sh
./deploy.sh
```

Скрипт:

- соберёт образ (с кэшированием библиотек ⚡)
- остановит предыдущий контейнер (если был)
- поднимет новый контейнер с volume `./data → /data` (БД и логи сохраняются между перезапусками)

### Быстрый деплой обновлений

При обычном деплое Docker кэширует слой с библиотеками, обновляется только код:

```bash
git pull
./deploy.sh  # Быстро! Библиотеки не переустанавливаются
```

Если обновили зависимости в `requirements.txt`, используйте форсированную пересборку:

```bash
./deploy.sh --force  # Пересобирает всё с нуля
```

Логи в консоли:

```bash
docker logs -f hyperliquid-trader-watcher
```

Файлы логов доступны на хосте:

```bash
ls -lht ./data/logs/
cat ./data/logs/app_latest.log
```

## Переменные окружения

Все настройки читаются из `.env`, параметры — в `settings.py`.

- **BOT_TOKEN**: токен Telegram-бота
- **BOT_ADMINS**: Telegram user ids админов (через запятую)
- **HL_POLL_INTERVAL_SECONDS**: частота опроса Hyperliquid (по умолчанию 10 секунд)
- **ONLY_MAJOR_POSITION_EVENTS**: режим алертов позиций (по умолчанию `true`)
  - `true` - только важные события: открытие/закрытие/разворот позиций (рекомендуется)
  - `false` - все изменения позиций выше порога `MIN_POSITION_CHANGE_PCT`
- **MIN_POSITION_CHANGE_PCT**: минимальный порог изменения позиции для алерта в % (по умолчанию 1.0, используется только если `ONLY_MAJOR_POSITION_EVENTS=false`)
- **LOG_LEVEL**: `DEBUG` или `INFO` (по умолчанию `INFO`)
- **MAX_LOG_FILES**: количество хранимых файлов логов (по умолчанию 50)
- **DB_PATH**: путь к sqlite БД (по умолчанию `./data/db/app.sqlite3`)
- **LOG_DIR**: директория логов (по умолчанию `./data/logs`)

## Логирование

Каждый запуск бота создаёт **новый файл лога** с timestamp:

```
./data/logs/
├── app_2026-01-02_14-30-45.log  # Запуск 1
├── app_2026-01-02_15-20-10.log  # Запуск 2
├── app_2026-01-03_09-15-33.log  # Запуск 3
└── app_latest.log -> app_2026-01-03_09-15-33.log  # Symlink на последний
```

**Преимущества:**
- Легко находить логи конкретного запуска
- Автоматическая очистка старых логов (хранится последние 50 по умолчанию)
- Symlink `app_latest.log` всегда указывает на текущий лог
- **Git версия в каждом логе** - точно знаете какой код запущен

**Пример лога при старте:**
```
2026-01-02 12:38:22 | INFO | root | ================================================================================
2026-01-02 12:38:22 | INFO | root | Bot started - Log file: app_2026-01-02_12-38-22.log
2026-01-02 12:38:22 | INFO | root | ================================================================================
2026-01-02 12:38:23 | INFO | __main__ | Git version: master@a1b2c3d (full: a1b2c3d4e5f...)
```

**Получить лог для анализа:**
```bash
# Последний запуск
cat data/logs/app_latest.log

# Конкретный запуск
cat data/logs/app_2026-01-02_14-30-45.log

# Список всех логов
ls -lht data/logs/app_*.log
```

## Как пользоваться

- Пользователь: `/start` → ожидание одобрения → `/menu` → “Трейдеры” → добавить адреса
- Админ: `/admin` (или кнопка “Админ‑панель”) → approve/deny пользователей, настройка доставки в канал
  - В карточке пользователя доступны переключатели типов алертов (✅/❌)

## Технические детали

- Telegram: `aiogram` (async)
- DB: SQLite + SQLAlchemy (async)
- Hyperliquid: `hyperliquid-python-sdk` (sync) обёрнут в `asyncio.to_thread()`

# Hyperliquid Trader Watcher 🚀

Простой скрипт для мониторинга информации о трейдерах на децентрализованной бирже Hyperliquid DEX.

## Возможности

Скрипт позволяет получить полную информацию о любом трейдере на Hyperliquid:

- 💰 **Total Value (Combined)** - общий баланс с детализацией:
  - Perp equity (позиции на деривативах)
  - Spot assets (токены на споте)
- 💵 **Withdrawable** - доступные для вывода средства (в USD и %)
- 📊 **Leverage** - текущее плечо (в USD и кратность)
- 📈 **Unrealized PnL** - нереализованная прибыль/убыток с ROE
- 🔹 **Открытые позиции** - все активные позиции с детальной информацией
- 📜 **История** - депозиты и выводы средств

## API Hyperliquid

Скрипт использует публичное API Hyperliquid (mainnet). Для получения данных не требуется API ключ или приватный ключ, так как вся информация о позициях и ордерах на Hyperliquid является публичной.

### Доступные методы:

- `info.user_state(address)` - Получение состояния аккаунта
- `info.open_orders(address)` - Получение открытых ордеров
- `info.user_fills(address)` - Получение истории сделок
- `info.user_funding(address)` - Получение истории финансирования
- `info.meta()` - Получение метаинформации о бирже

## Примечания

- Все данные на Hyperliquid являются публичными и доступны по адресу кошелька
- Скрипт работает только в режиме чтения (не выполняет сделки)
- Для тестирования можно использовать любой публичный адрес трейдера на Hyperliquid
