# Обновление UI - Постоянная клавиатура ⌨️

## Что изменилось

Вместо команды `/menu` теперь используется **постоянная клавиатура** (Reply Keyboard) - кнопки всегда видны внизу экрана.

### До:
```
Пользователь: /menu
Бот: [показывает inline меню]
```

### После:
```
Пользователь: /start
Бот: Добро пожаловать! 
     [показывает постоянную клавиатуру внизу экрана]
     
Кнопки всегда видны:
┌─────────────────┐
│    Трейдеры     │
├────────┬────────┤
│ Админ  │ Настр  │  ← Только для админов
│ панель │ ойки   │
└────────┴────────┘
```

## Изменения в коде

### 1. `app/bot/keyboards.py`
- ✅ Добавлена функция `main_keyboard(is_admin: bool)` - создает постоянную клавиатуру
- ✅ Импорт `ReplyKeyboardMarkup` и `KeyboardButton`
- ✅ Сохранен `main_menu_kb()` для обратной совместимости с inline меню

### 2. `app/bot/routers/user.py`
- ✅ Обновлен `/start` - показывает постоянную клавиатуру после одобрения
- ✅ Добавлены обработчики текстовых кнопок:
  - `"Трейдеры"` → показывает список трейдеров
  - `"Админ-панель"` → открывает админку (только для админов)
  - `"Настройки"` → показывает настройки (только для админов)
- ✅ Проверка прав доступа для админских кнопок

## Преимущества

1. ✅ **Удобнее** - не нужно вводить `/menu`, кнопки всегда на экране
2. ✅ **Быстрее** - один клик вместо ввода команды
3. ✅ **Нативнее** - выглядит как обычное приложение
4. ✅ **Безопаснее** - админские кнопки показываются только админам

## Технические детали

**ReplyKeyboardMarkup** с параметрами:
- `resize_keyboard=True` - автоматически подстраивает размер кнопок
- `persistent=True` - клавиатура остается видимой даже после отправки сообщения

**Логика доступа:**
- Кнопки создаются на основе `user.is_admin`
- При нажатии на админские кнопки дополнительно проверяется статус
- Если не админ - показывается "Эта функция доступна только администраторам"
